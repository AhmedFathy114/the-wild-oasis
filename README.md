## 📖 Description

**The Wild Oasis** is a full-featured hotel management dashboard built with React.

The application provides hotel staff with a centralized interface to manage bookings, cabins, guests, check-ins, check-outs, users, and hotel performance.

The dashboard also provides visual insights into sales, occupancy rates, bookings, and stay durations.
